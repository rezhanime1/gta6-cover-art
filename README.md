Vice Cover — a GTA 6-style cover art maker built for the [make.fun gta6-cover-art-01 bounty](https://make.fun/bounty/gta6-cover-art-01).

Upload a photo (or use the built-in samples), pick a panel layout and a preset (Sunset / Neon / Noir), type a title and subtitle, and it renders a multi-panel GTA-style poster on canvas — striped sun, palm silhouettes, halftone texture, bold condensed lettering — then exports it as a PNG in 1080×1080, 1080×1350 or 1920×1080.

Run it with `node serve.ts` (http://localhost:8080), or build with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
